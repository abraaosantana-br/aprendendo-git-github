CONCEITOS

Entenda o Git e o GitHub

Conheça os principais conceitos utilizados no controle de versões.

01

Git

O Git é um sistema de controle de versões utilizado para registrar as alterações realizadas em um projeto.

02

GitHub

O GitHub é uma plataforma online que permite hospedar repositórios e compartilhar projetos.

03

Repositório

É o local onde ficam os arquivos do projeto e o histórico de suas alterações.

04

Commit

Um commit registra um conjunto de alterações e cria um ponto no histórico do projeto.

05

Clone

O clone cria uma cópia local de um repositório remoto, incluindo seu histórico.

06

Versionamento

Permite acompanhar a evolução do projeto, comparar alterações e recuperar versões.

GIT × GITHUB

Qual é a diferença?

Git e GitHub trabalham juntos, mas possuem funções diferentes.

O Git controla as versões do projeto no computador. Já o GitHub permite armazenar esse projeto online e colaborar com outras pessoas.

Git

GitHub

COMANDOS

Principais comandos do Git

Estes comandos fazem parte do fluxo básico de desenvolvimento.

git clone

Copia um repositório remoto para o computador.

git add

Prepara as alterações para o próximo commit.

git commit

Registra as alterações no histórico.

git push

Envia os commits para o GitHub.

$ git clone repositorio

$ git add .

$ git commit -m "Adiciona estrutura inicial"

$ git push origin main

✓ Alterações enviadas com sucesso!
